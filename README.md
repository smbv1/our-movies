# Наши фильмы

Общий список фильмов и сериалов для просмотра вдвоём: у каждого свой аккаунт, список один на пару. Пет-проект.

Что умеет:
- поиск фильмов, сериалов и людей (TMDB), страницы тайтлов и фильмографии;
- статусы «хотим» и «посмотрели», отметки «кто хочет», синхронизация в реальном времени;
- оценки 1–10 и заметки у каждого из пары, прогресс по сериалам;
- фильтры по жанру, длине, десятилетию, оценке и «где смотреть»;
- случайный выбор по условиям, режим свайпов, рекомендации, статистика пары;
- PWA: можно установить на телефон.

Стек: Next.js 16 (Vercel) + Supabase (вход, Postgres с RLS, Realtime) + TMDB API.

## Настройка

### 1. Supabase
1. Создай проект на [supabase.com](https://supabase.com).
2. **SQL Editor** → по очереди вставь и выполни (**Run**) все файлы из `supabase/migrations/` по порядку номеров.
3. **Authentication → Sign In / Providers → Email**: для простоты выключи **Confirm email** (иначе после регистрации нужно подтверждать почту).
4. **Project Settings → API**: скопируй `Project URL` и `anon public` ключ.

### 2. TMDB
1. Зарегистрируйся на [themoviedb.org](https://www.themoviedb.org) и запроси API-ключ в **Settings → API**.
2. Скопируй **API Read Access Token** (длинный токен).

### 3. Локальный запуск
```bash
cp .env.example .env.local   # и заполни значения
npm install
npm run dev
```

### 4. Деплой на Vercel
1. **Add New → Project** → импортируй этот репозиторий.
2. В **Environment Variables** добавь `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `TMDB_API_TOKEN`.
3. **Deploy**.

## Как пользоваться
1. Один из вас регистрируется и нажимает «Создать новый список».
2. На главной странице виден код приглашения: второй регистрируется и вводит этот код.
3. Ищите фильмы и сериалы, добавляйте их и отмечайте просмотренные.

## Безопасность
- Секреты хранятся только в переменных окружения (`.env.local` локально, Environment Variables на Vercel) и не попадают в git: `.env*` в `.gitignore`.
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` публичный по замыслу Supabase и виден в браузере. Доступ к данным ограничивает Row Level Security: каждый видит только свой список, его участников и его фильмы (см. `supabase/migrations/`).
- `service_role` ключ Supabase приложению не нужен; никогда не добавляй его в переменные с префиксом `NEXT_PUBLIC_`.
